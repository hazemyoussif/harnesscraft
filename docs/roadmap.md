# Roadmap

## 0.1 — foundation

- Canonical engineering skills.
- Profiles for minimal, local, balanced, and frontier use.
- Portable installer and doctor.
- Pi repo-context, web-search, and safety-gate adapter.
- Contract validation for skill metadata and profiles.

## 0.2 — evidence and evaluation

- Skill activation fixtures.
- Small task corpus for architecture/review/delivery behavior.
- Regression checks for duplicated or contradictory guidance.
- Measured token footprint per profile.

## 0.3 — capability portability

- Decide which Pi tools justify an MCP transport.
- GitHub/CI status capability if it measurably removes repeated tool loops.
- Documentation lookup abstraction only if native search is insufficient.

## Later

- Community skill packs without expanding the core profile.
- Organization overlays layered on top of HarnessCraft rather than forks.
- Signed release manifest and stronger installer provenance checks.
